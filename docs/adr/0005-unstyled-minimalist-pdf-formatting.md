# 5. Unstyled / Minimalist PDF Formatting

Date: 2026-09-10

## Status
Accepted

## Context
The customer summary is an executive technical summary POC. Overly decorative branding is unnecessary and can distract from the core clarity of the data.

## Decision
Produce clean, unstyled, structured PDF documents focusing on clear typography, tabular layout for metadata, and clean hierarchy for the 6 report sections.

## Consequences
- Fast, reliable PDF rendering with minimal dependencies.
- High readability for facility contacts across devices and printouts.
